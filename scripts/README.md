## This folder includes the python scripts to do specific tasks 

### Generate the MoreSMIRK dataset
The MoreSMIRK dataset is generated by running the script 'GenerateEventSeq.py'. The output image sequences for the different events are written to [../datasets/MoreSMIRK/raw_data/](../datasets/MoreSMIRK/raw_data/) and placed in corresponding folders 'event_i'. These event folders contains two childfolders 'evt_i' and 'evt_i_anno' corresponding to the rgb and annotation image sequences, respectively.  

The script 'GenerateEventSeq.py' can be run with either of two options -s or -i. The image sequence of a single event is generated by using the -s option, e.g. event 2 is generated by
```
python GenerateEventSeq.py -s 2
```

The -i options is used to generate the image seqeunces for an interval of events, e.g. all the 104 events of the MoreSmirk dataset is generated by
```
python GenerateEventSeq.py -i 0 103
```

For the script to work, it is necesssary that the following folders and files exist
1. The original single pedestrian crossings from left-to-right and right-to-left with paths [../datasets/smirk/N09pgUrFChEH8GM6APzJ0](../datasets/smirk/N09pgUrFChEH8GM6APzJ0) and [../datasets/smirk/aITx4TyRncKnardhTgCzz](../datasets/smirk/aITx4TyRncKnardhTgCzz).
2. The background enviroment image [../datasets/MoreSMIRK/empty_smirk.png](../datasets/MoreSMIRK/empty_smirk.png).
3. The file [../datasets/MoreSMIRK/MoreSmirkEvents.yml](../datasets/MoreSMIRK/MoreSmirkEvents.yml) which contains the definitions and necessary parameter values to generate all the 104 events.
